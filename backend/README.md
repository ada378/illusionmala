# Illusion Mala Backend

Node.js + Express REST API for Gudiya Anda Mala products.

## Setup

```bash
npm install
npm run dev
```

## API Endpoints

- `GET /` - API info
- `GET /api/products` - Get all products
- `GET /api/products/:id` - Get product by ID

## Environment Variables

Create a `.env` file:

```
PORT=5000
NODE_ENV=development
```
