## 🚀 Installation & Setup

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend will run on: `http://localhost:3000` or `http://localhost:3001`

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

Backend API will run on: `http://localhost:5001`
